# AI + Selenium Full Project

## Objective

Design a Selenium framework with AI support for:

- page objects
- base test classes
- config management
- utilities
- reporting hooks

## What to Build

- framework folder structure
- page object generation prompts
- reusable login and navigation actions
- test examples for positive and negative flows

## Why This Matters

This project shows how AI reduces startup time for traditional enterprise automation stacks.
