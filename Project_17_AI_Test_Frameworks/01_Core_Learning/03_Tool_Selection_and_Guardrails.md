# Tool Selection and Guardrails

## When to Use What

- `Selenium`: legacy ecosystems, enterprise Java stacks, large existing suites
- `Playwright`: modern browser testing, better built-in waiting, stronger DX
- `API frameworks`: contract-first, high-speed validation, service-level coverage
- `Appium`: mobile workflows, device coverage, gesture-heavy testing

## Guardrails for AI Use

- define architecture before prompting
- provide coding conventions explicitly
- require code-only or structured output where needed
- review AI output against existing framework standards
