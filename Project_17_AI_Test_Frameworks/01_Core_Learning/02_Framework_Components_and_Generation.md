# Framework Components and Generation

## Common Components AI Can Help Generate

- page objects
- API clients
- POJO or DTO classes
- configuration readers
- environment profiles
- test data builders
- reporting utilities
- fixture and setup code

## Review Checklist

Before accepting generated code, check:

- naming consistency
- single responsibility
- retry and wait strategy
- hardcoded values
- logging quality
- error handling
- folder placement
