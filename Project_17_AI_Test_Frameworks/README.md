# Project 17: AI + Test Frameworks

## Build Better QA Frameworks with AI Assistance

This project is the bridge between basic AI usage and serious automation engineering.

The goal is to show how AI can help a QA engineer design, scaffold, review, and extend test frameworks across Selenium, Playwright, API testing, and mobile testing.

---

## What This Project Covers

This project is organized into four learning layers:

1. `Core learning`
Understand where AI fits inside test framework architecture.

2. `Learning exercises`
Practice framework design, prompt writing, and AI review patterns.

3. `QA projects`
Work through 3 starter project ideas that can later become full implementations.

4. `Parent project guide`
Use this README to understand the structure and the recommended order.

## Core Learning Topics

Inside `01_Core_Learning`, students should learn:

- where AI helps in framework design
- how prompts can generate framework building blocks
- how to review AI-generated code before trusting it
- how to decide between Selenium, Playwright, API, and Appium-based workflows

---

## Learning Exercises

Inside `02_Learning_Exercises`, students practice:

- converting a user story into framework components
- generating API data models and helper layers with AI
- reviewing bad AI-generated automation code and correcting it

---

## QA Projects in This Folder

### 1. AI + Selenium Full Project
Use AI to scaffold a layered Selenium framework with Page Objects, utilities, config handling, and test data patterns.

### 2. POJO Generation + API Framework Setup
Use AI to derive request-response models and setup helpers for an API automation framework.

### 3. AI + Playwright (Stagehand-style workflow)
Use AI to assist in generating Playwright flows, selectors, action steps, and validation helpers.

---

## Suggested Order

1. Read the `Core Learning` notes first.
2. Complete the 3 `Learning Exercises`.
3. Pick one `QA Project` and expand it into a real implementation.
4. Compare AI-generated output with your own framework standards.

---

## What Students Should Achieve

By the end of this project, students should be able to:

- explain how AI speeds up framework bootstrapping
- identify where AI output is useful and where it is risky
- design framework prompts with stronger constraints
- turn AI suggestions into maintainable test architecture
