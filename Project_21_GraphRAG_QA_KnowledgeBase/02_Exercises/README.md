# Graph RAG QA Knowledge Base: Exercises

## Practice Goal

Use these exercises to turn the topic into QA-ready thinking and implementation steps.

### Focus Exercise: Graph thinking workshop

1. Model a checkout feature as nodes and relationships in a QA graph.
2. Write three natural-language questions that require multi-hop graph reasoning.
3. Define an ingestion plan for requirements, bugs, and test cases.
4. Compare how vector RAG and Graph RAG would answer the same impact-analysis question.

## Stretch Tasks

1. Turn one exercise into a mini design document before writing any code.
2. Identify the inputs, outputs, risks, and validation checks for the workflow.
3. Explain how you would demo this topic to a QA team in under five minutes.
4. Define one measurable success criterion for the solution.

## Exercise Flow

```mermaid
flowchart TD
    A["Learn the concept"] --> B["Apply it to a QA scenario"]
    B --> C["Design the workflow or artifact"]
    C --> D["Review the risks and edge cases"]
    D --> E["Present the final reasoning"]
```

## Deliverable Ideas

- one-page architecture note
- prompt draft or evaluation rubric
- pseudo-code or workflow diagram
- checklist for QA review or release readiness
